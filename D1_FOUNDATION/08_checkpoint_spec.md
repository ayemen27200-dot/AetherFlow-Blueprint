# Checkpoint Specification

## Format example
```json
{
  "version": 1,
  "executor": "propainter",
  "chunks_completed": [0, 1, 2],
  "last_frame_idx": 900,
  "temp_files": ["/tmp/aetherflow/chunk_0.mp4"],
  "resume_token": "opaque-random-token"
}
```

## Mandatory fields
- `version`, `executor`, `chunks_completed`, `resume_token`

## ProPainter
- Strategy: `chunked_with_overlap`
- Chunk: 300 seconds
- Overlap: 30 seconds
- Blending: `linear_crossfade`
- Validate output continuity; artifacts may remain at boundaries, especially during fast motion.

## Whisper
- Chunk on detected silence where practical.
- Overlap defaults to 0 unless a tested model-specific strategy is defined.

## Safety
Checkpoint paths must be generated by the application, constrained to a dedicated temp directory, and cleaned according to retention policy. Do not accept arbitrary resume paths from clients.
