# D2 — MVP Scope (Sprint 1)

## الهدف
إثبات المفهوم: مهمة `split` من البداية للنهاية على VPS.

## داخل النطاق
- Orchestrator باستخدام FastAPI وSQLite WAL.
- طابور دائم بترتيب الأولوية ثم الأقدم.
- FFmpeg Executor مع stream copy (`-c copy`).
- عميل CLI باستخدام Typer.
- Docker Compose + Caddy.
- `POST /jobs`, `GET /jobs`, `GET /jobs/{id}`, `GET /health`.
- تحقق من الملف والحجم والمسار وتسجيل حالة التنفيذ.

## خارج النطاق
- Whisper وProPainter، واجهة Web، Agent الهاتف، السحابة، SSE، Telegram.

## المدة
خمسة أيام عمل كهدف تخطيطي، وليست وعداً زمنياً.

## معيار G2
يُرسل فيديو مدته ساعتان، تُنفذ مهمة التقسيم، تصبح النتيجة قابلة للوصول عبر API وتظهر المهمة بحالة `completed`. يجب قياس المدة على VPS وملف ممثلين.

## المخاطر
| الخطر | التخفيف |
|---|---|
| FFmpeg غير مثبت | تثبيته ضمن صورة التنفيذ مع تثبيت/توثيق الإصدار |
| مساحة تخزين ناقصة | فحص المساحة وتطبيق تنظيف آمن بعد 24 ساعة وفق السياسة |
| Caddy لا يحصل على شهادة عامة | التحقق من DNS والجدار الناري؛ `tls internal` للتطوير فقط |
| مسار ملف غير آمن | لا تقبل مسارات اعتباطية من العميل؛ استخدم مجلد إدخال مسموحاً به |
