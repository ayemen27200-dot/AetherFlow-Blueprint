## 2. تصميم العزلة الجديد في `verify_compose_stack.sh`

- **المجلد**: `WORK_DIR=$(mktemp -d ${TMPDIR:-/tmp}/aetherflow-smoke.XXXXXX)` مع
  حارس يرفض أي مسار خارج النمط المتوقع؛ `rm -rf` يطال هذا المجلد فقط.
- **المشروع**: اسم فريد لكل تشغيل، مع رفض صريح للاسم الثابت `aetherflow`؛
  كل أوامر Compose تمر عبر مصفوفة تحمل `-p "$PROJECT"`، فلا يمكن لـ`down -v`
  أن يلمس مكدسًا آخر (وحدات التخزين تحمل بادئة المشروع الفريد).
- **الصورة**: وسم فريد `aetherflow-smoke:<run-id>` يُبنى ويُحذف للتشغيل وحده.
- **الربط**: ملف override يعيد توجيه ربط `/app/data` و`env_file` إلى مجلد
  العمل؛ السكربت لا ينشئ ولا يعدل `.env` المستودع إطلاقًا، ويتحقق أن الإعداد
  المعروض لا يربط `data/` المستودع.
- **الصلاحيات**: env مؤقت 0600، شجرة البيانات 0750، وتُنقل ملكيتها لـuid 1000
  عبر `docker compose run --user root ... chown` (دون جذر مضيف ودون 0777).
- **إثبات عدم التدخل (القسم 11)**: لقطة قبل/بعد لحاويات المشروع الثابت
  `aetherflow` (إن وجدت) بمقارنة نصية، ولقطة `find data -type f` قبل/بعد
  بفرق `diff -u`، وتأكيد عدم إنشاء `.env` في المستودع.

## 3. الاختبارات والأوامر

```bash
bash -n scripts/verify_compose_stack.sh scripts/benchmark_long_media.sh scripts/install_vps.sh
ruff check .
pytest -q                       # 199 passed محليًا، تخطّيان بيئيان فقط
pytest tests/unit/test_verifier_isolation.py -v   # 8/8
bash scripts/benchmark_long_media.sh              # قياس كامل بخصائص الوسائط
```

اختبارات الانحدار تثبت: وجود mktemp، غياب أي حذف لـ`data/` المستودع، المشروع
الفريد ورفض الاسم الثابت، teardown مقصور عبر مصفوفة COMPOSE، env 0600 وغياب
0777، إعادة توجيه الربط للمجلد المؤقت، لقطات عدم التدخل، وإلغاء مسار 0777 في
المُثبّت مع التوقف الإلزامي عند فشل الـchown.

## 4. ما بقي مفتوحًا (لا اعتماد قبله)

1. إعادة نجاح `compose-smoke` بالسكربت المعزول على الرانر (رقم التشغيل يُلحق
   بالسجل القسم 8).
2. قياس VPS بملف ممثل، أو قرار مراجعة موثق للسقفين 15ث/60ث مع خطة التحسين.
3. شهادة Let's Encrypt عامة على مضيف بـDNS حقيقي.
4. تدقيق أسرار شامل لكل المكونات.

## 5. حوكمة

لم تُغيَّر عقود OpenAPI ولا مخطط DB، ولم تُدفع أي أسرار، وكل العمل على فرع
الجلسة دون دمج. G2 تبقى مفتوحة بانتظار إعادة التدقيق.
