# D3 — Acceptance Criteria (G3)

## Functional
- [ ] تفريغ عربي على VPS يصدّر SRT/VTT/JSON ويُراجع ضد عينة مرجعية.
- [ ] تفريغ محلي عبر whisper.cpp يعمل على جهاز هاتف مدعوم.
- [ ] Heartbeat كل 30 ثانية؛ بعد 90 ثانية offline وفق الاختبار.
- [ ] SSE يعرض تقدم المهمة النهائية في Web UI.
- [ ] صفحات dashboard/detail/settings تعمل مع HTMX.
- [ ] النفق الخاص يعيد الاتصال بعد انقطاع اختباري.

## Non-functional
- [ ] تقاس LCP وCLS وفق إعداد اختبار واضح.
- [ ] axe-core دون مخالفات critical، مع توثيق serious والاستثناءات.
- [ ] لا تمرير أفقي عند 320/360px.
- [ ] تنقل كامل بلوحة المفاتيح ووضع dark/light واضحان.
- [ ] المتصفحات المدعومة موثقة ومختبرة.

## Edge cases
- [ ] الهاتف ضعيف الذاكرة: رفض أو اختيار آخر وفق قواعد مفعلة ومختبرة.
- [ ] Agent offline أثناء التنفيذ: المهمة تصبح stalled وفق سياسة محددة.
- [ ] قطع SSE: العميل يعيد الاتصال دون تكرار غير محدود.
- [ ] عدم تسريب مسارات الملفات أو الرموز عبر الواجهة.

## Deliverables
- [ ] Whisper executors وAgent protocol
- [ ] صفحات templates والملفات الثابتة
- [ ] scripts موثقة للشبكة الخاصة
- [ ] `tests/integration/test_transcription_e2e.py` و`test_sse.py`

## G3
مراجعة عملية لتفريغ عربي وواجهة متجاوبة؛ تُعتمد البوابة بالأدلة وليس بوجود ملفات فقط.
