# D5 — Accessibility Audit (WCAG 2.2 AA)

## Perceivable
- [ ] كل صورة ذات معنى لها alt مناسب؛ الصور الزخرفية alt فارغ.
- [ ] تباين النص يحقق 4.5:1 للنص العادي و3:1 للنص الكبير حسب المعيار.
- [ ] الحالة لا تعتمد على اللون وحده.
- [ ] تكبير 200% وإعادة تدفق دون فقد المحتوى.

## Operable
- [ ] جميع الوظائف قابلة بلوحة المفاتيح.
- [ ] `:focus-visible` واضح ولا يحجبه عنصر ثابت.
- [ ] أهداف اللمس تحقق WCAG 2.2 SC 2.5.8 مع الشروط والاستثناءات، ويفضل 44×44 CSS px للتصميم.
- [ ] تقليل الحركة عبر `prefers-reduced-motion`.
- [ ] لا وميض خطير.

## Understandable
- [ ] `lang` و`dir` صحيحان.
- [ ] كل حقل له label وتعليمات عند الحاجة.
- [ ] الأخطاء مفهومة ومرتبطة بالمدخلات.
- [ ] التنقل والأنماط متسقة.

## Robust
- [ ] HTML صالح تقريباً وفق مدقق مناسب.
- [ ] `aria-live="polite"` للتقدم دون إفراط في الإعلانات.
- [ ] حالات المهمة تُمثّل دلالياً.
- [ ] مراجعة يدوية مع قارئ شاشة.

## الاختبارات
- axe-core/Lighthouse/WAVE للاختبار المساند.
- اختبار لوحة مفاتيح فقط واختبار قارئ شاشة.
- اختبر العربية RTL، المقاسات 320/360px، dark mode، والأخطاء والحوارات.

## مخرجات التدقيق
احفظ التقرير ونسخة الأداة وتاريخ التشغيل والصفحات المختبرة والإعاقات المعروفة. لا تكتب "شهادة WCAG" لمجرد أن axe-core لم يُظهر مخالفات.
